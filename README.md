# animalcountllm

API นับสัตว์จากภาพกล้องความร้อน ตอบเป็น JSON: **ชนิดสัตว์ · จำนวน · ค่าความเชื่อมั่น 0-1**

สร้างขึ้นสำหรับ POC ระบบเตือนภัยช้างป่า กล้องส่งภาพเข้ามาทุก 10 วินาที
บริการนี้ **ตอบคำถามอย่างเดียว ไม่เตือนใคร ไม่สั่งงานใคร** edge box ที่เรียกเป็นคนตัดสินใจเอง

## ทำงานยังไง

```
POST /v1/frames  {camera_id, ts, image_base64}
   │
   ├─ [1] บันทึกดิบทันที ก่อนทำอะไรทั้งสิ้น
   ├─ [2] CV  : normalize → แยกก้อนร้อน → นับก้อนที่ติดกัน → วัด bbox/area/aspect
   │           └─ ไม่มีก้อนขนาดสัตว์เลย → ตอบ 0 ตัว **ไม่ยิง LLM** (ประหยัด >90%)
   ├─ [3] VLM : ก้อนนั้นคือสัตว์อะไร
   ├─ [4] ถ้า confidence < 0.60 → provisional รอเฟรมถัดไปยืนยัน (สูงสุด 2 เฟรม)
   ├─ [5] กรองตามเวลา: Hampel (median+MAD) + hysteresis เทียบหน้าต่าง 100 วิ
   └─ JSON กลับ: ค่าดิบ + ค่าที่กรองแล้ว + เหตุผล + สภาพหน้าต่าง
```

**จำนวนมาจากชั้น CV ไม่ใช่จาก LLM** เพราะ CV รันภาพเดิมกี่ครั้งก็ได้ผลเดิมเป๊ะ
ส่วน LLM ถามสองครั้งได้สองคำตอบ หน้าที่ของ LLM คือบอกว่าก้อนนั้น**คืออะไร**

## เริ่มใช้

```bash
pip install -r requirements.txt
cp .env.example .env        # แล้วเติมคีย์
python tests/test_cv.py     # 10 ข้อ
python tests/test_filters.py # 12 ข้อ
uvicorn app.main:app --reload --port 8080
```

**เทสต์ทั้ง 22 ข้อรันได้โดยไม่ต้องมี LLM ไม่ต้องมี GPU ไม่ต้องมีเน็ต**
ชั้น CV กับชั้น filter เป็น deterministic ล้วน พิสูจน์ตัวเองได้ก่อนจะไปเถียงเรื่องโมเดล

## ค่าความเชื่อมั่นมีสองตัว อย่าปนกัน

| | มาจาก | เชื่อได้แค่ไหน |
|---|---|---|
| `detection_confidence` | CV | วัดได้ อธิบายได้ทีละพจน์ ทำซ้ำได้เป๊ะ |
| `species_confidence` | VLM | **โมเดลพ่นออกมาเอง ยังไม่ calibrate** 0.9 ไม่ได้แปลว่าถูก 90% |

`/v1/frames/{id}/truth` มีไว้บันทึก ground truth ที่คนตรวจแล้ว
**ไม่มีข้อมูลนี้ = calibrate ไม่ได้ตลอดกาล** และย้อนไปเก็บทีหลังไม่ได้

## ข้อจำกัดที่ต้องรู้ตั้งแต่วันแรก

ภาพความร้อนไม่มีสี ไม่มีลาย เหลือแค่รูปทรงกับความต่างอุณหภูมิ
**ช้าง ควาย วัว ที่ระยะ 50 ม. ขึ้นไปคือก้อนขาวคล้ายกันหมด**
ที่แยกได้จริงคือสัดส่วนรูปร่างกับขนาดเชิงมุม ซึ่งแปลเป็นขนาดจริงไม่ได้ถ้าไม่รู้ระยะ

`unknown` จึงมีอยู่ใน `counts` เสมอ ก้อนที่ระบุไม่ได้ไปอยู่ตรงนั้น
**ไม่ยัดเป็นช้างเพื่อให้ตัวเลขสวย**

รายละเอียดการออกแบบทั้งหมดอยู่ใน `CLAUDE.md`
